Your next plan in five steps

  1. Replace the business fields with your actual business, audience, offer and next step. Choose a start date and posting rhythm. Weekday schedules begin on the first matching day on or after that date.
  2. Build a plan. The six purposes repeat in a balanced sequence: Teach, Show, Connect, Answer, Invite and Listen. These are reusable editorial rules, not AI-generated advice. An idea set starts from a different part of the library.
  3. Choose a post, adapt its brief and write the actual caption. Use Apply edits, or Save/Export, to keep the current editor changes. Ready and Published are labels you set yourself.
  4. Use Calendar to check dates. CSV and Print export the entire plan, regardless of the current filters. Your offer or profile changes affect a newly built plan, not existing briefs.
  5. Save project downloads a JSON file with your plan and drafts. Open project restores it. Nothing is automatically saved between visits. Keep files somewhere you trust and share only information you intend to disclose.

Desktop Chrome was tested. Other browsers and spreadsheet editors may render differently. Open the downloaded HTML in a browser; mobile file handling varies. CSV is an interchange file, not a direct integration with a social scheduler. There is no auto-posting, account connection or reminder service.
