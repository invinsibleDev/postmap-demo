# PostMap — free content planning demo

Build a seven-post plan from 12 original editorial briefs, edit captions, check a calendar and export CSV or PDF. No account, AI key or subscription is required.

[Open the free demo](https://invinsibledev.github.io/postmap-demo/)

[Full PostMap kit: 60 briefs and plans up to 60 posts — $15](https://aleksi41.gumroad.com/l/postmap)

The demo is a static browser workspace. It does not send your inputs to a server. Save project downloads a JSON file; Open project restores it. There is no automatic saving between visits, automatic posting or reminder service. The built-in business and example caption are fictional.

Desktop Chrome was tested. The workspace and briefs are in English. Mobile file handling and print support depend on your device.

You may use the free demo to create your own or client posts and keep personal copies. The original brief library and interface may not be redistributed or sold as a competing template product. Your original writing remains yours. No engagement, reach or income guarantee.
